VowKy 1.6.3 Release Notes

- Name your recordings: while a recording is in progress, type a name in the new "Save as" bar at the bottom of the window; when you finish, the .md and .wav are saved under that name and it appears in History too. Leave it blank to keep the default timestamp name
- Safe naming: if a file with that name already exists, VowKy appends -2, -3, … automatically — companion files such as the subtitle log and bilingual transcript are counted as well — so no earlier recording is ever overwritten
- Pressing Esc inside the name field only leaves the field; it no longer triggers "Cancel recording"
- The "Save as" bar also shows where the files go and their formats, and displays the final file name once the recording is done
